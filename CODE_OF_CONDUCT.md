# Code of Conduct

This project follows standard open-source community expectations modeled after the Contributor Covenant:

- Be respectful, constructive, and considerate in issues, pull requests, and discussions.
- Focus feedback on technical merit, reproducibility, and user impact.
- Harassment, personal attacks, or discriminatory remarks are not tolerated.

Report unacceptable behavior by opening a private contact or flagging an issue for the repository maintainer (`@supta69k`).
